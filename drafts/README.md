# Drafts

Every file here was written by the agent with `status: needs_approval`. Nothing in this folder has been sent.

Approval flow:
1. Open the draft, read the guardrail findings and handoff notes at the bottom.
2. Fix or accept. Fill any `[NEEDS: ...]` placeholder.
3. Set `status: approved` and `approved_by:` in the front matter, then send it yourself from the rep's mailbox or hand it to print.

Re-check an edited draft at any time: `npm run check -- drafts/<file>.md email`
